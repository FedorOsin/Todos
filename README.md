# Todos

Проект по Todos основанный на React+Redux+RTKQuery

## Описание

Это простое приложение для управления задачами (To-Do List), разработанное на React. Пользователи могут добавлять, редактировать и удалять задачи, а также отмечать их как выполненные. Приложение использует Redux Toolkit для управления состоянием.

## Технологии

- React
- TypeScript
- Redux Toolkit
- Tailwind CSS
- Vite
- ESLint
- Prettier

## Установка

Инструкции по установке проекта на локальную машину.

**Todo проект (Vite):**

1.  **Клонируй репозиторий:**

    ```bash
    git clone https://github.com/FedorOsin/Todos/tree/main
    cd Todos
    ```

2.  **Установи зависимости:**

    ```bash
    npm install
    # или
    yarn install
    # или
    pnpm install
    ```

3.  **Запусти приложение:**

    ```bash
    npm run dev
    # или
    yarn dev
    # или
    pnpm dev
    ```

    Приложение будет доступно по адресу [http://localhost:5173](http://localhost:5173).

## Использование

> После запуска приложения вы увидите список задач.
>
> - Чтобы добавить новую задачу, введите текст в поле ввода и нажмите кнопку "Добавить".
> - Чтобы отметить задачу как выполненную, щелкните по ней.
> - Чтобы удалить задачу, нажмите кнопку удаления.
> - Вы также можете редактировать задачи.
